# FlowLens 1.3 实施计划

目标是让用户把一套相关表格组织成应用，在同一项目中完成多单据办理，并把可恢复的应用包交给下一位实施者。

| 顺序 | 交付内容 | 验收条件 |
| --- | --- | --- |
| 1 | 应用、项目、模板入口与角色待办 | 新建应用并选入导入的模板，项目资料可复用，台账按项目筛选 |
| 2 | 指令、回复、复查三张单据及映射 | 从已完成的上游发起下游，带入字段和来源修订，重复点击返回同一单据 |
| 3 | 重复明细 | 增删检查行，校验列类型和阶段必填，汇总数值，打印及导出恢复后完整保留 |
| 4 | 自然语言规则预览 | 常用必填、角色、条件退回语句产生可确认草案，未识别或有歧义时提供明确提示 |
| 5 | 跨单据过程与交付 | 查看关联记录、字段来源和事件，导出整个应用，恢复后继续办理 |
| 6 | 兼容与发布 | 旧工作包可用，测试和浏览器验收通过，更新双语 README、截图、版本、发布包与公开 demo |

规则识别首先采用本地受支持句式。项目与角色用于浏览器内业务推演。后续多人服务需要实现服务器身份、权限和持久化。

核心验收使用虚构监理项目。依次创建指令、整改回复、复查记录，验证必填拦截、条件退回、重提、来源带入、重复发起、不同项目隔离，以及导出恢复后继续完成业务。原始监理材料用于本地结构核对。

README 同步更新中英文页面。视频评估依据为入口和操作路径变化，优先录制新版多表过程，并分别提供中文和英文讲解。

实现和验收已完成，具体结果见 [1.3 发布记录](release-1.3.0.md)。
