# 公开演示版

演示版是纯静态网页，没有模型代理或可写的 AI 配置接口，不部署或保存 DeepSeek API Key。AI 生成关闭，其余交互、Word 本地导入、表单办理、设计编辑与三维部署样例可使用。

首次打开会创建一份原创的虚构工程检查表和草稿，直接点击提交后切换为专业监理，填写监理意见，再由资料员签收。实际客户的监理文件、工作包、附件不随演示发布。

所有业务内容保存在访问者当前浏览器，刷新可恢复；没有账号或跨设备同步。清理站点数据会清除存档，重要内容请导出。GitHub Pages 托管静态文件，业务填写不发送到模型。

## 构建与更新

```sh
npm ci
npm test
npm run build:demo
```

`dist/` 是可发布的文件集合，采用相对资源地址，支持 GitHub Pages 的项目子路径。只将此目录的内容发布到 `gh-pages` 分支根目录，Pages 使用该分支；不要将整个源码目录或本地工作包作为站点根目录。源码仍在 `main`，1.0 标签不变。

本机 `npm start` 保留模型配置能力。今后若开放在线 AI，需要另设服务端密钥、访问认证与额度限制；把密钥编码或加密后放进前端不能保护它。

1.2 默认演示改为指令、整改回复、复查与归档。旧浏览器存档不自动替换，点击“体验整改闭环样例”可追加新样例。系统设计与开发交付跟随当前选中的表；原型模型通过“切回独立原型实验室”进入。
