# FlowLens 1.15.0 · 把项目配置补齐

导入表格和流程以后，还要把办理人安排好。这一版在管理后台列出每个项目的办理角色和启用成员，缺少承办人的角色会直接显示出来。旧单据仍在使用的历史角色也会列入检查。

## 首次配置

空白实例首页可以直接进入配置。应用包没有项目时，页面说明如何在设计工作台补建项目，再通过更新预览发布。项目尚未建立时，授权保存按钮禁用。

点击项目的配置按钮可以定位到授权栏。保存后保留当前成员和项目，停用账号在成员列表中标注。角色检查只统计启用账号，实际职责沿用交付检查中的业务确认。

## 验收

125 项本地回归和 20 项独立运行包检查通过。隔离浏览器从空白实例开始，完成应用导入、补入两个项目、角色授权、第一份业务新建及普通成员登录。成员只看到获授权项目。停用与重新启用账号、历史角色跨分页、空白项目提示及 390 像素窄屏均已检查。

最终跨平台、云端升级和发行下载验收记录在[交付计划](delivery-plan.md)。实际业务职责、试点负责人和运维交接继续待确认。
