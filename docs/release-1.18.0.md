# 1.18 项目 Excel 台账（发行准备中）

当前代码版本为 `1.18.0-dev.1`，正式发行和云端仍为 1.17.0。这里记录候选版本的功能和验收，完成发布后再更新状态。

## 把项目中的表单带到 Excel

进入团队版项目，点击“下载 Excel 台账”。工作簿包含使用说明、各历史表式的主表，以及带所属单据编号的明细表。全部已保存单据都会导出，包括草稿和已归档记录，不受当前列表分页影响。

同一版本曾经使用不同字段时，按实际保存的字段结构分表。编号、日期和其他填写值都按文本保存，长编号不会变成科学计数法，前导零不会丢失，填写的公式文本不会执行。要在 Excel 中计算，请先确认并转换需要计算的列。

这是核对用台账，不是备份。它不包含附件文件和完整办理历史，也不能导入恢复系统。完整交接请同时下载项目资料包；实例恢复使用管理员数据库备份。

## 已完成的验收

- 本地完整回归 145 项通过，独立候选运行包原有 22 项检查通过；运行包测试新增 XLSX HTTP 下载检查。
- 本机 Excel 打开样例没有修复提示，长编号、前导零、中文换行和公式文本显示正确。
- 通过浏览器下载 57 份虚构业务，独立读取后比对全部单据编号、状态、342 个填写字段和 1 行明细，全部一致。文件包含两种历史表式，分别生成主表和明细表。
- 当前权限、停用账号、其他项目、空项目、同版本不同结构、最大单元格长度及超限拒绝均有覆盖。中断下载后可以重新导出，项目资料包和台账共用传输限制。
- 单次最多 200 张工作表、50 万单元格和 64 MiB 未压缩 XML；超过限制会明确失败，不返回部分工作簿。Excel 的单元格长度、工作表行列限制也在生成时检查。
