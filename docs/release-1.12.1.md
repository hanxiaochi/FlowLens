# FlowLens 1.12.1 · 新建入口与修订 0 草稿修正

2026-11-04

1.12.0 的补充验收发现两处新建业务问题，这个版本一起修正。

- 首次进入页面、尚未打开过单据时，新建按钮会误读取空编辑会话，出现错误。现在新建操作正常执行，已有单据提交时仍等待对应草稿完成保存。
- 没有项目资料预填的单据从修订 0 开始，原草稿校验误要求至少为 1。现在这类初始单据可以保存本机草稿、刷新后核对恢复，再完成第一次业务保存。

浏览器已从正常入口完成新建修订 0 单据、填写、下载并重读、刷新找回、核对恢复和保存至修订 1。新增自动测试覆盖空编辑会话、新建请求、其他单据、等待当前草稿及真实模型创建的修订 0。

113 项本地回归通过。独立候选运行包通过 16 项交付检查，其中直接载入打包后的草稿模块，检查首次新建和修订 0。完整功能与本机保存范围见 [1.12 功能说明](release-1.12.0.md)。

建议使用本修订版替换 1.12.0。升级前保存或下载当前填写，升级后刷新页面。数据库 schema 保持 2，本机已保存草稿的格式沿用 1.12.0。

跨平台 CI 已通过，覆盖 Windows、Ubuntu、容器及 Compose。[CI 记录](https://github.com/hanxiaochi/FlowLens/actions/runs/41733738801)

云端已备份升级到 1.12.1。五个账号的两项目、十份业务与升级前一致，公网浏览器已确认修订版页面。最终下载包、运行文件与备份核对继续记录在[交付计划](delivery-plan.md)。
