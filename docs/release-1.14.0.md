# FlowLens 1.14.0 · 发布前看清变化

管理员上传应用更新包后，先看字段、流程、摘要、关联和项目资料的变化，再确认发布。复杂表格可以展开前后对照，查看嵌套表格、合并单元格与列宽。

## 发布与恢复

- 另一位管理员修改配置后，旧预览会要求重新核对。日常填写可以继续。
- 发布请求先保存在当前浏览器。结果丢失后可刷新，再用原操作编号确认，避免重复记录发布。
- 浏览器存储空间不足时，页面保留预览并提示下载更新包，发布请求不会发出。
- 冲突请求可以重新预览，明确处理旧恢复记录后再确认。
- 原有单据保留创建时的表式快照。

新界面使用带基线保护的发布接口。旧 definitions 接口保留兼容行为，其直接调用方仍需自行处理并发。
