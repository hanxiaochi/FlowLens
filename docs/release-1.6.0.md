# FlowLens 1.6.0 · 附件存储与容量升级

2026-11-04

工程现场的照片、扫描件会很快超过一个小样例的体积。这次把协作服务的附件从工作区 JSON 中移出，按内容校验值保存在同一个 SQLite 数据库中。备份仍然是一份文件，表单读取只携带附件信息，点击时再下载。

## 本次变化

- 相同内容复用一份二进制数据，写入失败时随业务事务一起回滚。
- 下载时重新检查当前项目权限，并核对内容校验值。移出项目的账号无法继续下载。
- 管理员运行状态显示附件逻辑用量、实际存储用量及迁移记录。
- 下载支持取消，等待超过 120 秒会提示重试。网关采用已发布端口支持的 HTTP/1.1 与 HTTP/2。
- 旧数据首次启动时自动迁移，迁移前保存独立快照。迁移过程出错会回滚。

## 验收记录

79 项自动化测试通过，覆盖迁移回滚、历史请求重试、权限、附件去重、损坏检测及恢复。跨平台和容器验收可在仓库 Actions 查看。

同一隔离环境连续上传三份 8 MiB 合成附件，旧版本只能接受前两份。升级后全部接受，工作区 JSON 为 19,364 字节，数据库与备份为 25,321,472 字节。一次本机备份约 220 ms。这是可复现样例的比较，实际项目容量需要结合磁盘和负载测量。

云端已完成迁移前备份、原有四份业务记录核对、三份 8 MiB 附件上传与逐字节下载检查、恢复到新数据库后的附件核验。为方便复验，保留了一份明确标注用途的合成容量草稿及三份测试文件。浏览器完成了小文件上传下载、大文件下载和慢下载取消检查。

## 升级与回退

1. 停止旧版本业务服务，使用旧版备份命令保存一致性快照，保留旧程序。
2. 确保磁盘有数据库快照和整理所需空间，再启动 1.6。数据库结构由版本 1 升至 2，程序会在原数据库旁创建 `.before-attachments-<uuid>.sqlite` 快照。
3. 登录核对业务、项目成员、附件和一次完整办理，执行新备份并验证恢复。
4. 如需回退到 1.5，停止 1.6，将升级前的结构版本 1 备份恢复到新的数据库路径，再用 1.5 启动。1.5 无法打开结构版本 2 数据库。回退前保存升级后产生的数据并安排核对。

新客户端使用 `X-FlowLens-Client: 2` 获取附件引用，旧客户端继续获取内联附件。旧协议超过 24 MiB 原始附件总量时会提示刷新。单文件上限 10 MiB、单业务附件合计 30 MiB，工作区元数据上限 32 MiB。独立附件仍占用服务器磁盘，设计端便携 JSON 导入继续受原有大小限制。

真实业务表式与责任人、持续异地备份安排、整机重启窗口及完整证书续期周期仍在交付清单中跟进。
