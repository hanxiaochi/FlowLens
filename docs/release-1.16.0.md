# FlowLens 1.16.0 · 把已有台账带进来

在项目的表式卡片中选择“从 CSV 导入”，把台账列对应到填写字段，核对预览，再创建一批可继续办理的草稿。需要先有该表式的填报角色。

## 导入前先核对

编号按文字保留，支持引号中的逗号、双引号和换行。预览显示格式错误、项目带入值覆盖和提交前缺项，每页 50 行，可筛选错误行及同批重复填写行。重复提示按已映射字段值比较，确认后各行都会创建草稿。重新映射保留文件和选择。

使用 UTF-8 CSV，每批最多 500 行、200 列、2 MiB。整批仍受实例 3000 份业务及工作区 32 MiB 限制。上游关联表式沿用已有发起规则。

## 确认与恢复

请求先保存在当前浏览器。服务端在事务内整批写入，并核对账号、实例、表式与项目。响应丢失后可继续确认原请求，重复确认返回原批次结果。新建另一个导入请求会创建另一批草稿，请先核对已有业务。

预览后表式或项目变化会要求重新核对。恢复列表可下载原 CSV 和完整请求，核对服务器结果后处理旧记录，再重新预览。存储空间不足时保留预览，提示下载原文件。

## 验收

137 项本地回归通过。浏览器覆盖正常导入、保留映射、52 行分页错误定位、同批重复提示、读取中断、提交后 API 断线、存储配额不足及基线变化。核对后成功导入 52 份草稿，下载回执包含 52 个编号，其中一份补齐必填项后进入总监签发，原有五份业务保持一致。

独立运行包 21 项检查通过。容量争用、事务末尾故障回滚、并发原请求、权限撤销及 CLI 还原后旧实例请求拒绝也已验证。最终 CI、云端升级与发行下载记录在[交付计划](delivery-plan.md)。实际业务规则及试点验收仍待业务负责人确认。
