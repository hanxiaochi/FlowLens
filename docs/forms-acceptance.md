# 业务表单验收记录

验收日期：2026-11-01。对应本地未发布的业务表单增量，不改变 1.0 标签。

## 老板的意见如何落到产品

“表格 + 工作流”成为业务表单入口：表格保存业务内容，工作流规定谁在什么阶段填写、审核或接收。全过程保持同一份业务编号，保留模板快照、修改与办理历史。复杂原表是验收载体，不用简化请假单代替。
